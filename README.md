# Epoxy Flooring Prescott

Source for prescotteliteepoxyflooring.com. Pages are generated by `build.mjs` into `public/` and served by a Cloudflare Worker (`src/worker.js`), which also receives the estimate form at `/api/lead`.

## Pages

- `/`
- `/garage-floor-coating/`
- `/basement-and-interior-epoxy/`
- `/chip-flake-floors/`
- `/polyaspartic-topcoats/`
- `/polyurea-coatings/`
- `/porch-walkway-patio-coatings/`
- `/commercial-epoxy-floors/`
- `/hangar-warehouse-floors/`
- `/about/`
- `/communities/`
- `/contact-us/`
- `/privacy/`

Service pages live in `src/content/services/` (one file per page, registered in `index.mjs`).
